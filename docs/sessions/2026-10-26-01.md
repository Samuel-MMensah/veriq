## How to check it yourself
1. Run `npm run build && VERIQ_DATA=local npx next start -p 3100`, and open http://localhost:3100/results?service=antenatal&card=nhis&lat=5.545&lng=-0.265&area=dansoman in a 390 px window.
2. You should see "Near Dansoman: services not listed yet" and the group "Services not listed. Call to ask", starting with Dansoman Polyclinic (1.9 km). Each card shows "NHIS not confirmed yet" and "From the NHIA list, October 2026". There is no SAMPLE DATA tag.
3. Tap Dansoman Polyclinic. You should see POLY2005 · Dansoman · Ablekuma, the source line, "Map location from OpenStreetMap" with its credit, and "Reporting opens soon".
4. Open /emergency. You should see real hospitals marked "Emergency not checked. Call first".
5. Add `&demo=1` to the results link. You should see the 4 demo hospitals with SAMPLE DATA, and Gbawe has a Call button. `?demo=0` goes back.
6. Open /admin, tap Demo login, then open a district under "Needs a location" and save "5.5612, -0.2601".
