## How to check it yourself
1. In Supabase, open Table editor → facilities. You should see 18 rows, all with `is_sample = true`.
2. Open card_reports: it should hold 75 rows. In the SQL editor, run `select count(*) from public_card_reports where outcome = 'refused' and created_at > now() - interval '30 days' and insurer_id = 'a0000000-0000-4000-8000-000000000001';`. The answer is 23.
3. To load the seed again, run `npx supabase db push --db-url "<your SUPABASE_DB_URL>" --include-seed`. The CLI re-seeds only when `seed.sql` has changed. Otherwise, paste `seed.sql` into the SQL editor.
