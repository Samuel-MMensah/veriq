## How to check it yourself
1. Run `npm run dev`, open http://localhost:3000/admin/calls and sign in with your admin account.
2. Tap "Record a call", search "madina", and choose Madina Polyclinic. Fill in "Front desk" and "030 254 1234", set NHIS to Accepts, and press "Save the call". The call shows at the top.
3. Open "What the calls found". NHIS shows 1 asked, 1 matching the list. "Download CSV" gives the same numbers.
4. Open that facility as a patient: /facility/{id}?card=nhis. You should see "Takes NHIS · Veriq call · just now" and "Phone and services: Veriq call, {date}", and the Call button dials the number.
5. On /admin/calls/import, download the template, paste a row, and press Preview. Nothing saves until you press "Save 1 call".

## Decisions I made
All are also in docs/DECISIONS.md:
- **Badge ids** `BV` and `BVx`. Partial adds " · with top-ups". B1 is unchanged.
- **"A newer hospital answer always wins"** means any hospital answer at or after the call, even one too old for B2.
- **Saving:** one database function per call, all or nothing; calls are append-only, real facilities only, one per facility and moment.
- **Older calls** (paper typed in later) never overwrite newer facts.
- **Usual hours** are saved on the services named in the same call only.
- **A location from a call** is `location_source = admin`, like the location tool.
- **The phone reached** must be a callable number; it's stored as digits.
- **Summary definitions:** the newest answer per facility and card; partial counts as accepting; the official list follows rule K's reading.
- **The CSV** uses `facility_ref` (the source row), because the NHIA file has no codes.
- **The caller** is an active admin account. The demo admin can look, not save.
- **Kasoa:** it's outside the Greater Accra list, so the four nearest listed facilities on the Kasoa road are used.
- **Rule K** still counts B2 only (see Questions).

## Problems and risks
- **Two of the five insurers in the table are invented** (Sika Health, Adom Care, from the demo seed). The form asks about every insurer, so callers will see them. Default is "Not asked": medium.
- **The 30 facilities have no phone numbers** in the NHIA file. The team must find each number before calling: medium.
- **Local data mode only:** the first staff sign-in right after a server starts sometimes doesn't stick (a second try works). The e2e specs warm the server first. The real site uses Supabase Auth: low.
- **Result and emergency cards** show a Call button for a Veriq-call phone without saying its source. The hospital page does say it: low.
