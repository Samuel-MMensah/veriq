## What grew, and the speed numbers
- **Page weight barely changed since Prompt 9.** Gzipped, /find was: JS 188.3 → 188.7 KB, CSS 6.5 → 8.3 KB, HTML 4.4 → 4.6 KB, font 27.3 KB both.
- **Server work didn't grow either.** Live time to first byte is about 0.43 s even for a cached static page.
- **What changed was the network path from here to Vercel:** 105–220 ms per round trip today.
- **Why that hit first paint:** the one render-blocking stylesheet request was queued behind ~188 KB of async scripts on a 750 kb/s line, so every slow round trip delayed it.

Same 3G profile, locally, Prompt 9 build → Prompt 10 build → this fix:

| Added latency | Prompt 9 | Prompt 10 | This fix |
| --- | --- | --- | --- |
| 100 ms (the e2e profile) | 0.88–0.90 s | 0.98–0.99 s | 0.37–0.38 s |
| 400 ms (closer to today's live path) | 1.46–1.48 s | 1.53–1.57 s | 0.58–0.71 s |

In the e2e perf test (local build, after the fix): 0.34–0.42 s on all 5 screens.

On the live site:
- **Before** (Prompt 10 build): 1.2–2.0 s this session; the review's runs that morning gave 1.6–2.6 s and 2.0–2.8 s.

2. Find → Antenatal / maternity → Cosmopolitan Health → Show hospitals. You should see Akoma "Takes Cosmopolitan Health", Lakeside "5 patients confirmed…", Gbawe "On insurer list…", and Glefe last, "Patients report … refusals".
