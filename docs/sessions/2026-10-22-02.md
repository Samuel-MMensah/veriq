## How to check it yourself
1. Run `npm install`, then `npm run dev`, and open http://localhost:3000
2. In the browser's mobile view at 390 px, you should see "First open" with the bottom bar at the bottom.
3. Tap Find: you see "Find care" with the orange SAMPLE DATA tag, and Find turns green.
4. Tap Cards ("My cards", no tag), Saved ("coming in the pilot" note) and Help ("Help: USSD and SMS").
5. Open http://localhost:3000/h/check: you see "Hospital morning check" with the tag and no bottom bar.
6. Open http://localhost:3000/manifest.webmanifest: the name is "Veriq Health".
7. Run `npm run lint`, `npm run typecheck`, `npm test` and `npm run e2e`. The first time, run `npx playwright install chromium` before `npm run e2e`.
