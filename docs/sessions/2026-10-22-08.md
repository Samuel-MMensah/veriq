## How to check it yourself
1. Run `npm run dev` and open http://localhost:3000. This uses your live Supabase project. To use fresh sample data instead, run with `VERIQ_DATA=local`, e.g. `$env:VERIQ_DATA="local"; npm run dev` in PowerShell.
2. Tap "Get started". On Find, keep Antenatal / maternity and NHIS, and tap "Show hospitals that take NHIS".
3. You see "4 hospitals near Dansoman": Akoma (green, confirmed by hospital), Lakeside (light green, 14 patients), Gbawe (grey, NHIA list), and Pinecrest last (orange, 9 refused).
4. Tap Akoma. You see Today (open till 4 pm, accepting, available, from 2 pm), then NHIS / Cosmopolitan "Yes" and Prudential "Unsure", each with its history table, and the GH¢ 80 scan top-up.
5. Go back to `/`: it now goes straight to Find.
