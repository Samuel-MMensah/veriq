## How to check it yourself
1. Run `npm run build && VERIQ_DATA=local npx next start -p 3100`, open http://localhost:3100 in a phone-sized window.
2. First open: tap "Emergency" (top right). Emergency mode opens, with Call and Go on each unit.
3. Go back, tap Get started, then Show hospitals that take NHIS. Each card leads with "Takes NHIS", "NHIS not confirmed yet" or "Patients report NHIS refusals".
4. Open Akoma: the header says "Takes NHIS · Confirmed by hospital 2 days ago". Under Cards accepted, tap "More" to see the 7-day, 30-day and 12-month table.
5. Open http://localhost:3100/results?service=dental&card=prudential&lat=5.69&lng=-0.03&area=ashaiman&r=2 to see the new empty state.
6. Reload `/`: you land on /find with no welcome flash.
