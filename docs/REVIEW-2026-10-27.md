# Veriq Health: build review, 27 October 2026

A review only: no app code, data, config or deployment was changed to write it. Checked against `SPEC.md` (as of commit 7b81f0b), the live site, the database (read-only counts) and a full local test run. Where something is not built, stubbed or uncertain, it says so.

## 1. Summary

Veriq Health is a mobile-first web app for Ghana that shows, before you travel, which hospitals really accept your insurance card, what is open today, and what patients actually paid. Every fact shows its source and age.

**On the live site today (https://veriqhealth.vercel.app):**
- **Patients** can search the real NHIA list of 417 accredited Greater Accra facilities, labelled "From the NHIA list, October 2026", and open emergency mode. These facilities carry only what that list says: no phones, no services, no opening times. Only 57 have a map location.
- **Demo mode** (`?demo=1`) shows 18 invented demo hospitals with the full story: badges, today's status, top-ups and patient reports, tagged SAMPLE DATA.
- **Staff** (admin, hospital, insurer) sign in with email and password. Accounts are made by an admin; nothing is emailed.
- **Patient reporting on real hospitals is switched off** until the Data Protection Commission registration.

The project is in **Phase 2 (pilot)**:
- The Phase 1 gate was met on 2026-10-24.
- Prompts 9 and 10 are done and deployed.
- The Phase 2 gate is not met.

### The NHIA import

- **Source:** NHIA "Providers" page, https://nhis.gov.gh/providers, region Greater Accra. Taken 26 October 2026: 419 rows, saved unedited as `data/nhia/greater-accra-2026-10-26.csv`. Sources and caveats are in `data/nhia/SOURCE.md`.
- **The file we were first given** (`data/nhia/Greater_Accra_Hospitals_Insurance_List.pdf`) was not an NHIA document ("compiled from information shared in this conversation"). It is not used and is not committed.
- **Imported:** 417 rows. Two went to `data/nhia/import-report.md` instead: one duplicate, and Castle Clinic with type "5 B2".
- **Fields we have:** name, NHIA type as written (e.g. "PRIMARY HOSPITAL", "POLY2005"), district (old names from before the 2012 split, e.g. Ablekuma, Kpeshie), and area/location text. A few rows have no area.
- **Fields we don't have:** phone number, NHIA code, ownership type, services, opening hours, coordinates, and the date of the NHIA list itself. The page shows no date.
- **The list is incomplete.** Several large hospitals are missing, e.g. Korle Bu Teaching Hospital and Ridge.
- **Map locations (live database, counted today):**
  - 57 placed from OpenStreetMap: same name, inside the old district, only one such place.
  - 0 placed by an admin.
  - 360 with no location.
  - Facilities with no location never appear in a distance search or emergency mode (rule D1).
- **Verified hospitals (live): 0 of 417.**
- **Allowed facts:** each real facility has one NHIS row "listed by NHIA" (badge B4) and nothing else. `supabase/tests/directory.test.ts` fails if any real facility gets a status, report, service, top-up, hospital answer or private-insurer row.

### How real and demo data are kept apart

- **In the database:** `facilities.source` is `nhia` or `demo`, and a database check makes `source = demo` the same as `is_sample = true`.
- **In the app:** `visibleInMode` (`lib/rules/directory.ts`) shows only demo facilities in demo mode and only real ones outside it. Demo mode comes from `?demo=1` (an 8-hour cookie) or the demo login.
- **SAMPLE DATA tag:** shown only while a demo facility is on screen. Tested both ways in `tests/e2e/directory.spec.ts`.
- **"Reset demo data"** deletes and re-seeds only `is_sample` rows. Tested: real rows are unchanged after a reset.
